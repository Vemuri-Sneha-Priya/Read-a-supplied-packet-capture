# Milestone 4 – Submission Guide

## A. Complete the official task
1. Download the official starter pack: https://api.edbytes.in/api/v1/public/curriculum/TASK-CS-03/starter.zip
2. Extract it and read `START-HERE.md`.
3. Keep an untouched copy of the original files.
4. Open the supplied synthetic `.pcap` in Wireshark.
5. Apply `http` and record the actual method and path.
6. Apply `dns` and record the actual requested training name.
7. Read `PASS-CHECKLIST.md` and compare with `EXAMPLE-OUTPUT.md`.

## B. Capture evidence
1. Save a screenshot showing the HTTP filter and selected request details.
2. Save a screenshot showing the DNS filter and selected query details.
3. Annotate screenshots so the relevant fields are clear.
4. Store both in this repository's `screenshots/` folder.
5. Do not include private or unrelated network traffic.

## C. Create a separate GitHub repository
1. Open https://github.com/new while signed in.
2. Repository name: `edbytes-packet-capture-analysis`
3. Choose Public if using it as a viewable evidence link.
4. Upload this folder's contents and commit them.
5. Verify that the repository opens in a private/incognito browser window.

Expected URL after creation:
`https://github.com/Vemuri-Sneha-Priya/edbytes-packet-capture-analysis`

## D. Submit to EdBytes
1. Open Milestone 4 → Submit Deliverables.
2. Provide one view-only report link in the evidence field.
3. Add the GitHub repository URL in the companion source/note field if available.
4. Verify both links open without requesting access.

This folder contains report templates, not the actual packet capture or verified analysis. Replace every prompt with observations from the official synthetic capture before submission.
